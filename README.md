#  Freelance Marketplace

این پروژه یک پلتفرم ساده فریلنسری است که در آن کارفرماها می‌توانند پروژه ثبت کنند و فریلنسرها برای انجام آن‌ها پیشنهاد ارسال کنند.

## قابلیت‌ها

- ثبت‌نام، ورود و خروج کاربران
- ثبت، ویرایش و مشاهده پروژه‌ها
- جست‌وجو و فیلتر پروژه‌ها
- ارسال پیشنهاد برای پروژه‌ها
- پذیرش یا رد پیشنهادها توسط کارفرما
- مشاهده و ویرایش پروفایل کاربران
- پنل مدیریت برای مشاهده کاربران و پروژه‌ها

## تکنولوژی‌های استفاده‌شده

- **Frontend:** React
- **Backend:** Node.js و Express
- **Database:** PostgreSQL

## پیش‌نیازها

برای اجرای پروژه به موارد زیر نیاز دارید:

- Node.js نسخه 20 یا بالاتر
- PostgreSQL نسخه 17
- ایجاد یک پایگاه داده با نام `fixflow`

## نحوه اجرای پروژه

### 1. اجرای Backend

در پوشه اصلی پروژه دستورات زیر را اجرا کنید:

```bash
npm install
```

سپس جداول دیتابیس را ایجاد کنید:

```bash
psql -U postgres -d fixflow -f db/migrations/001_mvp.sql
```

برای افزودن اطلاعات نمونه:

```bash
npm run seed
```

در نهایت سرور را اجرا کنید:

```bash
npm start
```

### 2. اجرای Frontend

در ترمینال جدید دستورات زیر را اجرا کنید:

```bash
cd react/my-react-app
npm install
npm run dev
```

پس از اجرا، برنامه از آدرس زیر در دسترس خواهد بود:

http://localhost:5173

آدرس Backend:

http://localhost:8080

## حساب‌های آزمایشی

پس از اجرای دستور `npm run seed` می‌توانید با حساب‌های زیر وارد شوید.

**رمز عبور تمام حساب‌ها:**

`Demo1234`

- کارفرما: `employer@demo.local`
- فریلنسر: `freelancer@demo.local`
- فریلنسر: `sara@demo.local`
- مدیر: `admin@demo.local`

## اجرای تست‌ها

برای اجرای تست‌های پروژه از دستور زیر استفاده کنید:

```bash
npm test
```
