Jira Task Breakdown – MVP
Assignee: Arvin Mohammadi
Status: Done 
MV-1: Authentication
Implement user registration, login, logout, and password security.
MV-2: Password Recovery
Add password reset functionality with secure, time-limited links and request limits.
MV-3: Project Listing
Display available projects with search and category filters.
MV-4: Project Details
Show project descriptions, employer information, budget, skills, and deadlines.
MV-5: Create and Edit Projects
Allow employers to create, edit, save, and publish projects.
MV-6: My Projects
Provide a dashboard where employers can manage their projects and view proposals.
MV-7: Submit Proposals
Allow freelancers to submit proposals with their price and estimated completion time.
MV-8: My Proposals
Allow freelancers to view and withdraw their pending proposals.
MV-9: Review Proposals
Allow employers to accept or reject proposals submitted to their projects.
MV-10: User Profile
Allow users to view and edit their personal and professional information.
MV-11: User Interface
Implement a responsive Persian RTL interface with proper notifications and form validation.
MV-12: Database and Testing
Prepare database migrations, sample data, and automated tests.
